# Нодовый редактор стейт-машин

Визуальный редактор конечных автоматов (FSM) с экспортом в JSON. Написан на
чистом HTML/CSS/JavaScript — без зависимостей и сборки.

## Запуск

Просто откройте `index.html` в браузере:

```bash
# вариант 1: открыть файл напрямую
xdg-open StateMachineEditor/index.html      # Linux
open StateMachineEditor/index.html          # macOS

# вариант 2: через локальный сервер
cd StateMachineEditor
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Возможности

- **Состояния (ноды)** — двойной клик по холсту или кнопка «＋ Состояние».
  У состояния есть имя, флаги «начальное»/«конечное» и списки действий
  `onEnter` / `onExit`.
- **Переходы (рёбра)** — перетащите синий порт ● с правого края ноды на другую
  ноду (или на ту же — получится петля). У перехода есть событие-триггер,
  условие (guard) и приоритет.
- **Навигация** — колесо мыши масштабирует, перетаскивание фона панорамирует.
- **Редактирование** — клик по ноде или метке перехода открывает панель
  свойств; `Del` удаляет выбранный элемент, `Esc` снимает выделение.
- **Экспорт/импорт** — кнопки «Экспорт JSON» (скачивает файл),
  «Копировать» (в буфер обмена) и «Импорт» (загрузка `.json`).
- **Автосохранение** — текущая схема хранится в `localStorage` браузера.

## Формат JSON

```json
{
  "name": "TrafficLight",
  "initialState": "Red",
  "states": [
    {
      "name": "Red",
      "isFinal": false,
      "onEnter": ["SetLamp(red)"],
      "onExit": [],
      "editor": { "x": 100, "y": 80 }
    }
  ],
  "transitions": [
    {
      "from": "Red",
      "to": "Green",
      "event": "timer",
      "condition": "",
      "priority": 0
    }
  ]
}
```

| Поле | Описание |
| --- | --- |
| `name` | Имя стейт-машины. |
| `initialState` | Имя начального состояния (или `null`). |
| `states[].name` | Уникальное имя состояния — служит идентификатором. |
| `states[].isFinal` | Признак конечного состояния. |
| `states[].onEnter` / `onExit` | Списки действий (строки в свободном формате). |
| `states[].editor` | Координаты ноды на холсте. Рантайм может игнорировать это поле. |
| `transitions[].from` / `to` | Имена состояний-источника и цели. |
| `transitions[].event` | Событие-триггер перехода. |
| `transitions[].condition` | Условие (guard) в свободном формате; пустая строка — без условия. |
| `transitions[].priority` | Приоритет при конфликте нескольких переходов (больше — раньше). |

Пример готового файла: [`examples/traffic-light.json`](examples/traffic-light.json) —
его можно загрузить в редактор через «Импорт».
