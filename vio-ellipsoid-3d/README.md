# Эллипсоид неопределённости VIO в коридоре

Учебная 3D-сцена (Three.js) для интуиции о наблюдаемости и информационной
матрице в визуально-инерциальной одометрии (VIO).

## Запуск

Нужен любой статический сервер (es-modules не работают с `file://`):

```bash
cd vio-ellipsoid-3d
python3 -m http.server 8000
# открыть http://localhost:8000
```

Three.js подтягивается с CDN (jsDelivr), сборка не нужна.

## Математическая модель (честно об упрощениях)

- **Состояние** — только позиция телефона `p ∈ R³`. Ориентацию не оцениваем,
  её считаем известной точно — учебное упрощение (в настоящем VIO состояние
  включает ориентацию, скорость, смещения IMU и т.д.).
- **Bearing-измерение.** Каждая видимая фича `i` (внутри конуса поля зрения
  полууглом 35° и радиуса видимости 9 м) — это направление на точку, без
  дальности. Луч зрения `r_i` (единичный вектор от камеры к фиче) даёт
  информацию только в плоскости, перпендикулярной лучу:

  ```
  Λ += w_i · (I − r_i r_iᵀ),   w_i = 1/R_i,   R_i = R0·(1 + (d_i/D0)²)
  ```

  Шум `R_i` растёт с расстоянием `d_i` — дальние фичи весят меньше.
- **Фичи на однородных стенах** (флаг у фичи). Если стена без текстуры,
  оптический поток различает движение только **вдоль нормали стены** `n`
  (поперёк стены), а сдвиг вдоль стены неотличим. Такая фича даёт:

  ```
  Λ += w_i · n nᵀ
  ```

  и *не* даёт bearing-вклада. Именно поэтому в «Коридоре» с однородными
  боковыми стенами и полом не возникает информации вдоль оси коридора —
  λ_min проседает к нулю, направление вдоль коридора «тёмное».
- **Эллипсоид неопределённости** — из ковариации `P = Λ⁻¹`: полуоси вдоль
  собственных векторов `Λ`, длины ∝ `1/√(λ_i + eps)`. Вырожденное
  направление (λ < eps = 1e-9) рисуется длинной красной полуосью.
- **Прочие упрощения:** окклюзии не учитываются (фича видна сквозь стены,
  если попала в конус); измерения считаются независимыми; Λ пересчитывается
  с нуля в каждой позе (нет накопления по времени / фильтра).

## Собственное разложение

Симметричная 3×3 диагонализуется **методом Якоби** (циклическое зануление
наибольшего внедиагонального элемента вращениями Гивенса) — короткая
собственная реализация в `js/math.js`, без библиотек.

## Что смотреть

1. Пресет «Комната»: фичи на всех стенах → эллипсоид маленький и круглый.
2. Пресет «Коридор»: нажмите «Пройти маршрут» — на графике видно, как
   λ_min проседает почти до нуля в середине коридора и поднимается у
   дальнего торца, где появляется текстурированный «постер».
3. Проба d: направьте её вдоль коридора — dᵀΛd упадёт до ~0.
