## 📋 Сценарии использования документации

### Сценарий 1: "Хочу быстро понять что это"

1. Прочитайте **README.md** (раздел "Обзор архитектуры")
2. Посмотрите диаграммы в **ARCHITECTURE.md**
3. Прочитайте **PROJECT_SUMMARY.md** (раздел "Что создано")

**Время:** ~15 минут

---

### Сценарий 2: "Хочу попробовать консольное демо"

1. Прочитайте **QUICKSTART.md** (раздел "5-минутный старт")
2. Соберите проект: `dotnet build`
3. Запустите демо: `cd src/Workstation.Comms.ConsoleDemo && dotnet run`

**Время:** ~5 минут

---

### Сценарий 3: "Хочу интегрировать в Unity"

1. Прочитайте **UNITY_INTEGRATION.md** полностью
2. Следуйте пошаговой инструкции
3. При проблемах - см. раздел "Troubleshooting" в том же файле

**Время:** ~30 минут

---

### Сценарий 4: "Хочу реализовать серверную часть"

1. Прочитайте **SERVER_HUB_SPEC.md** полностью
2. Создайте WorkstationHub класс по образцу
3. Протестируйте с консольным демо
4. При проблемах - см. раздел "Troubleshooting" в **README.md**

**Время:** ~2 часа

---

### Сценарий 5: "Хочу понять архитектуру для code review"

1. Прочитайте **ARCHITECTURE.md** (раздел "Clean Architecture Layers")
2. Изучите диаграммы последовательности
3. Прочитайте **PROJECT_SUMMARY.md** (раздел "Архитектурные решения")
4. Просмотрите код основных классов:
   - `WorkstationClient.cs`
   - `SignalRTransportClient.cs`
   - `WorkstationClientBehaviour.cs`

**Время:** ~1 час

## 🎓 Дальнейшее изучение

После изучения документации рекомендуется:

1. **Изучить исходный код** в следующем порядке:
   - Domain/Interfaces → понять контракты
   - Domain/Entities → понять модели данных
   - Application/WorkstationClient.cs → понять логику
   - Infrastructure/SignalRTransportClient.cs → понять транспорт

2. **Запустить консольное демо** и:
   - Понаблюдать за логами
   - Попробовать все пункты меню
   - Симулировать ошибки

3. **Создать простую интеграцию**:
   - Unity: минимальная сцена с подключением
   - Сервер: минимальный хаб

4. **Прочитать код примеров**:
   - `Program.cs` в ConsoleDemo
   - `WorkstationClientBehaviour.cs` в UnityAdapter
